#Inventory Management

## Project Overview

The inventory managemtn system is a python-based application designed to help users organize, track, and manage inventory efficiently and accuratly.

Users can create inventory items, assign them to categories, and manage important details such as item names and quantities

The system will allow users to view, add, update, remove, and search the items in the inventory. It will also have an inventory summary to help users monitor the stock level and keep inventory records organized.
